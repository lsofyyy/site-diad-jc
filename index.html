Linguagens

Toque em um cartão para ver para que serve e um mini exemplo.

HTML

O esqueleto

toque para virar

Para que serve

Define a estrutura da página: títulos, textos, imagens e botões.

<h1>Olá!</h1>
<button>Clique</button>

CSS

A roupa

toque para virar

Para que serve

Deixa tudo bonito: cores, tamanhos, posições e animações.

h1 {
  color: purple;
  font-size: 3rem;
}

JavaScript

O cérebro da página

toque para virar

Para que serve

Faz a página reagir: cliques, jogos, contas e mensagens.

botao.onclick = () => {
  alert("Oi!");
};

Python

Simples e poderosa

toque para virar

Para que serve

Automação, análise de dados e inteligência artificial.

for i in range(3):
    print("Olá", i)

Java

toque para virar

Aplicativos Android, sistemas de bancos e grandes empresas.

System.out.println(
  "Olá, mundo!");

VS Code: a oficina

          
🔧 É como uma oficina: tem bancada, ferramentas e tudo à mão para montar o projeto.

          
Todo o site foi escrito em três arquivos de texto, dentro de uma pasta:


site-diad-jc/
├── index.html    ← o esqueleto
├── style.css     ← a roupa e o movimento
├── script.js     ← o cérebro
└── assets/       ← a logo e o ícone
