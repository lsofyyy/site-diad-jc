# Site do curso de Desenvolvimento de Sistemas

Site de apresentação do curso, feito por alunos do **CETI Gov. João Clímaco D'Almeida**.

- **Tecnologias:** HTML, CSS e JavaScript puros. Sem frameworks, sem npm, sem CDN (funciona offline).
- **Arquivos:** `index.html` (estrutura), `style.css` (visual e animações), `script.js` (lógica e gerador de QR code), `assets/` (logos e ícone).
- **Como abrir:** abra a pasta no VS Code e use a extensão *Live Server* (ou dê dois cliques no `index.html`).
- **Feedback por QR code:** crie o formulário rodando `extras/criar-forms.gs` em script.google.com e cole o link na constante `FORM_URL`, no topo do `script.js`.
- **Plataforma:** as matérias Pensamento Computacional e Mentorias TEC usam bibliotecavirtual.seduc.pi.gov.br.
- **Trocar a cor ao vivo:** edite as variáveis do `:root` no `style.css` (ex.: `--roxo-600`).
- **Publicação:** GitHub Pages (Settings → Pages → branch `main`, pasta raiz). Sem build.
- **Roteiro dos alunos:** veja `ROTEIRO-ALUNOS.md`.
